# ea-kernel-contract

`ea-kernel-contract` loads deterministic contract snapshots generated by `ea-kernel`.

Default snapshot source:
- `packages/ea-kernel/docs/reference/contracts`

Snapshot files:
1. `kernel_schema.snapshot.json`
2. `kernel_rules.snapshot.json`
3. `kernel_judgment_vectors.snapshot.json`

## Quick usage

```python
from ea_kernel_contract import load_contract_bundle

bundle = load_contract_bundle()
print(bundle.kernel_version)
print(len(bundle.vectors["vectors"]))
```

Optional environment override:

```bash
export EA_KERNEL_CONTRACT_DIR=/path/to/contracts
```
