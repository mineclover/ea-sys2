
# EA Kernel Visualization

A dedicated web application for visualizing the `packages/ea-kernel` structure and relationships.

## Features
- **Interactive Graph**: Visualizes kernel components using React Flow.
- **Data Driven**: Designed to import and display kernel profiles, specs, and rules.
- **Tech Stack**: React, Vite, TypeScript, @xyflow/react, D3.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
